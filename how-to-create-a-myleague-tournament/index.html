Ignore the 2's, 1's and 0's... they're meaningless. In the upper left corner of each box is the day of the month. Remember that this is East Coast time. The orange box is the current day.

Select the start time.

this is the "TD Setup page"

You can name the tour if you wish. If not, put a space instead... otherwise, the software will add a big ugly red "Cases Ladder" logo

For game, scroll down and select "Hockey"... or if you aren't just being silly, "Spades".

For "Game room name" you can type in the league name, but it's redundant. Almost everyone leaves this blank.

"format" means the Spades game... as long as it's understandable, phrase it as you please... for example, REG SPADES PARTNERS

Tourney style is normally Classic.

Number of rounds... over estimate is safest... I put 6 though, of course that never happens.

number of players per team:   for partners, two, for everything else, one

Teams competing per match of course, three for CUT, four for "true SINGLES", two for everything else.

Random partners... just what it says...

no membership requirement

no multiple day or invitation only (except for tournament of champion tours)

Ladder Stats, yes

"time between rounds"... doesn't really change anything for Spades, but you need to put something... I was taught to put 10, so I do

Ladderbux entry fee... most leagues have the same fee for every tour... All Spaders and Diamond Spaders tours all cost 200 ladderbux

finally, select "create tournament"

At this point, you're finished if you don't want to "decorate" your tour page.

If you *do*, select "Customize Tournament Layout"

you can choose different font colors (save as default if you wish)

this is a place for you to play around when you have time... it would take too long to explain it... but you can choose a differentfont obviously

Because I know HTML, I never use the "Top Image Link" or "EZ Picker"

Background image is useful... but you need get the URL for an image on the web... you can't upload one from your PC.

The center box for "Custom HTML" is just that. You write or copy and paste HTML here. If you don't know how to write HTML script, I can help ypu learn, if you'd like. I've taught several. I enjoy it.

This box is what I use to make my usual tour pages.

If you're directing a tour, you'll want to copy from the tour admin page and paste in the lobby, for example Im_Already_Gone vs Ochwiay... any other method is ridiculous.

note: the clipboard is a "stack"... last in, first out. If what you need to paste is not on top, you'll need to view your clipboard -- <winows key> + V  -- and select the item you want.
